## 3. 产品功能 + 最新动态 (timeline)

### 核心功能
- AI 会议记录员：以**机器人参与者身份**加入 Zoom / Google Meet / Microsoft Teams，自动录音、转写（25 种语言）、生成摘要、行动项、跟进邮件。
- "30 秒出摘要"（号称比竞品 5+ 分钟快 10x），平均每场会议省 38 分钟。
- **免费层极强**：无限录音 + 无限存储（永久）+ 无限转写；免费层每月仅前 5 场可用高级 AI 摘要。
- **Ask Fathom**：类 ChatGPT 对话式检索，可对会议内容提问（Premium 起）。
- CRM / 工具同步：Salesforce、HubSpot、Slack、Notion、Asana。
- 面向销售/CS：Deal View、CRM 字段同步、**AI Scorecards**（按可配置评分卡给通话打分、生成带时间戳的可指导片段）。

### 与 CallingClaw 的能力对比（关键差异）

| 能力 | Fathom | CallingClaw |
|------|--------|-------------|
| 加入会议方式 | **机器人参与者**（显示为 "Fathom Notetaker"，所有人可见）；2026 起新增**无机器人捕获**（本地音频/转写，Mac/Slack Huddle） | 作为真实参与者加入 Meet/Zoom |
| **会中实时说话 (SPEAK)** | **否** —— 纯被动记录，不发声、不对话 | **是** —— 实时双向语音对话 |
| 看共享屏幕 / 视觉 | 否（仅音频转写） | **是** —— VisionModule 看屏幕 |
| 控制电脑 / 执行动作 | 否 | **是** —— ComputerUse 控制 macOS |
| 双语 EN/中文 | 转写支持 25 语言，但产品定位英语市场 | **EN/中文 原生双语** |
| 本地运行 | 云端 SaaS（新增本地导出 CLI/MCP） | **本地运行** |

> **结论**：Fathom 是"被动记录 + 事后检索"型工具；CallingClaw 是"主动参与 + 实时发声 + 看屏 + 控机"的 agent。二者在"会议笔记/摘要"这一层重叠，但 CallingClaw 的实时交互与电脑控制是 Fathom 完全不具备的能力。

## 5. Marketing 内容 / 策略

- **核心定位**：「Never Take Notes Again」——**免费 + 快 + 准**。免费层极其慷慨（无限录音/存储/转写）是最大获客钩子，靠付费 AI 功能（Ask Fathom、Scorecards、CRM）转化。
- **PLG（产品驱动增长）**：通过 Zoom / Google Meet / HubSpot / Chrome Web Store 应用市场分发，HubSpot Marketplace 安装 2 万+，并被评为 HubSpot "2025 年度最常用 App"——借生态分发获客。
- **信任 / 社会证明驱动**：高调宣传 **G2 #1 最高满意度（5.0）**、海量好评、SOC2 Type 2、端到端加密、数据不用于训练——直接打消企业采购顾虑。
- **众筹叙事**：让 1,300+ 用户以 VC 同条款投资 $2M+，制造"用户即股东"的社区/忠诚度叙事，公关效果强（Foundersuite 专文报道）。
- **内容/SEO**：大量第三方测评/对比文章（vs Otter / Fireflies / Granola / tl;dv / Jamie 等）占据"AI notetaker"长尾关键词；官方 `/whats-new`、Help Center、Product Hunt 发布制造节奏。
- **发布节奏营销**：2026-04 用 "Fathom 3.0" 大版本 + Product Hunt #1 制造声量，叠加"bot fatigue（机器人疲劳）"这一行业痛点叙事推无机器人捕获。

### 常见抱怨（归纳）
1. **机器人可见**：以 "Fathom Notetaker" 参与者出现，所有人可见在录音，影响会议氛围（2026 bot-free 正是回应此点）。
2. **隐私 / 同意**：自动加入日历会议、自动录音引发同意顾虑；Google Meet 需"已验证参与者"。
3. **移动端缺失**（截至 2025-09 无原生 App，仅浏览器访问——2026-04 才推 iOS）。
4. 摘要语气死板、不可定制；多主题会议结构易混乱；偶发转写/时间戳不准。

## 7. 对 CallingClaw 的威胁评估

**直接竞争程度：中等。** 二者在"会议笔记/摘要/行动项/CRM 同步"这一层正面重叠，且 Fathom 体量大（$30M ARR、30 万+ DAU、G2 #1），是该品类事实标杆与采购默认项。

**Fathom 的护城河（CallingClaw 落后处）：**
- 巨大的免费层 + PLG 分发（HubSpot/Zoom/Chrome 商店）带来的规模与品牌；
- 海量五星评价构成的信任壁垒（G2 5.0/6,833 条）；
- 成熟的 CRM/销售情报（Deal View、Scorecards）与企业合规（SOC2）；
- 资本与团队规模（~150–170 人 vs CallingClaw）。

**CallingClaw 取胜处（Fathom 不具备）：**
- **会中实时发声与双向对话**（Fathom 永远被动）；
- **看共享屏幕 + 控制 macOS 执行动作**（agent 能力，Fathom 仅音频转写）；
- **原生 EN/中文 双语**与**本地运行**（隐私/数据主权）；
- 定位是"会议中的 AI 同事/agent"，而非"事后笔记本"——这是不同物种。

**风险信号（需警惕）：**
- Fathom 3.0 已加入 **MCP + ChatGPT/Claude 集成 + bot-free 本地捕获 + CLI/本地导出**，正从"notetaker"向"可被 agent 调用的会议情报层"靠拢。若其后续接入实时语音/agent 能力，重叠面会扩大。
- 其"免费 + 30 秒摘要"已极大压低了"会议笔记"这一价值点的付费意愿——CallingClaw 不应在"笔记/摘要"上正面竞价，而应强调**实时参与、发声、看屏、控机、双语**等 Fathom 结构性缺失的能力作为差异化主轴。

**建议定位话术**：不要把 CallingClaw 描述为"更好的 notetaker"，而是"会开口、会看屏、会动手的会议 AI 同事"——把 Fathom 归到"被动记录"象限，CallingClaw 独占"主动参与"象限。
